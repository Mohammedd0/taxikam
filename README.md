# یەکسا · Yeksa (وەشانی HTML)

دوو ئەپی جیا بە HTML و CSS و JavaScriptـی ئاسایی. پێویستی بە Node، npm یان دابەزاندن نییە.

```
taxikam/
├── index.html      لاپەڕەی هەڵبژاردن (سەرنشین / شۆفێر / پانێڵ)
├── shared/         کۆدی هاوبەش: ڕەنگ، فۆنت، زانیاری، یاساکان
├── passenger/      ئەپی سەرنشین
├── driver/         ئەپی شۆفێر
└── admin/          پانێڵی بەڕێوەبردن (بۆ خاوەنی ئەپ)
```

## دانان لەسەر XAMPP

1. فۆڵدەری `taxikam` کۆپی بکە بۆ `C:\xampp\htdocs\` (ئەگەر فۆڵدەرێکی کۆن بە هەمان ناو هەیە، سەرەتا بیسڕەوە).
2. لە XAMPP Control Panel، **Apache** دەست پێبکە.
3. لە کۆمپیوتەر: **http://localhost/taxikam/**
4. لە مۆبایل (هەمان وایفای): **http://192.168.0.103/taxikam/** (IP ی کۆمپیوتەرەکەت)

بۆ ئەوەی وەک ئەپ لەسەر شاشەی مۆبایل دەربکەوێت: لە Safari دوگمەی Share ← **Add to Home Screen**. ئەمە بۆ هەر دوو ئەپ جیا بکە.

> فۆنتی Noto Naskh Arabic لەناو پرۆژەکەدایە (`shared/fonts`)، بۆیە بێ ئینتەرنێتیش هەمان فۆنت دەردەکەوێت.

## Firebase (لە v23ـەوە)

هەموو زانیارییەکان لە Firebase هەڵدەگیرێن (Firestore و Authentication)، بۆیە سەرنشین، شۆفێر و بەڕێوەبەر هەر یەکەیان لە مۆبایلی خۆیەوە کار دەکات و هەموو گۆڕانکارییەک دەستبەجێ لای ئەوانی تر دەردەکەوێت.

- ڕێکخستنی پڕۆژە: `shared/firebase-config.js` (کلیلەکان، UIDـی بەڕێوەبەر، کلیلی Google Maps)
- یاساکانی ئاسایش: `firestore.rules`. **پێش هەموو شتێک دەبێت دابنرێن**، دەنا Firestore هیچ شتێک قبووڵ ناکات.
- هۆست: `firebase.json` و `.firebaserc`

### ١. دانانی یاساکانی ئاسایش (یەک جار، هەر کاتێک firestore.rules گۆڕا)

ڕێگای ئاسان، بێ دابەزاندنی هیچ: Firebase Console ← **Firestore Database** ← تابی **Rules** ← هەموو نووسینەکەی ناو `firestore.rules` کۆپی بکە و بیخە جێگای ئەوەی ئێستا ← **Publish**.

### ٢. تاقیکردنەوە لەسەر XAMPP

- لە کۆمپیوتەر: `http://localhost/taxikam/` (localhost خۆی ڕێگەپێدراوە).
- لە مۆبایل بە IPی کۆمپیوتەر (بۆ نموونە `192.168.0.103`): Firebase Console ← **Authentication** ← **Settings** ← **Authorized domains** ← **Add domain** ← IPـەکە بنووسە (بێ http). دەنا چوونەژوورەوە کار ناکات.

### ٣. هۆست لەسەر Firebase (ناونیشانی https)

یەک جار لەسەر کۆمپیوتەر:
1. Node.js (LTS) لە nodejs.org دابەزێنە و دایبنێ.
2. لە CMD: `npm install -g firebase-tools`
3. `firebase login` (بە هەمان هەژماری Google)

هەر جارێک کە فایلەکانت گۆڕی:
```
cd C:\xampp\htdocs\taxikam
firebase deploy --only firestore:rules,hosting
```
ناونیشانەکە: `https://taxiakam-6d28f.web.app` (ئەپی سەرنشین: `/passenger/`، شۆفێر: `/driver/`، پانێڵ: `/admin/`).

### ئەوەی دەبێت بیزانیت

- **ژمارەی مۆبایلی سەرنشین** تەنها لە `accounts` و `pax`دایە کە تەنها خۆی و بەڕێوەبەر دەیخوێننەوە. شۆفێر تەنها ناوی یەکەم دەبینێت و لە ڕێگەی نامەوە پەیوەندی دەکات.
- **بەڵگەنامەکانی شۆفێر** (کارتی نیشتمانی، مۆڵەت، ناونیشان، موچە) تەنها خۆی و بەڕێوەبەر دەیبینن. ناو، ئۆتۆمبێل، تابلۆ و وێنەی ڕووخسار گشتین.
- **وشەی نهێنی** لە Firebase Authentication هەڵدەگیرێت و کەس نایبینێت. سەرنشین و شۆفێر بە ژمارەی مۆبایل دەچنە ژوورەوە (لە پشتەوە ژمارەکە دەبێت بە ئیمەیڵێکی ناوخۆیی وەک `7501234567@p.taxikam.app`).
- **گۆڕینی وشەی نهێنی کەسێکی تر** لەلایەن بەڕێوەبەرەوە لەم وەشانەدا نییە (پێویستی بە Cloud Functions و پلانی Blaze هەیە). هەر کەسێک دەتوانێت وشەی نهێنی خۆی لە ڕێکخستنەکان بگۆڕێت.
- **وێنەکان** بچووک دەکرێنەوە (لە ١ مێگابایت کەمتر) و لە Firestore هەڵدەگیرێن (کۆلێکشنی `img`). وێنەیەک کە پێش دروستکردنی هەژمار هەڵبژێردراوە (تۆمارکردنی شۆفێر) دوای دروستبوونی هەژمار خۆکار بار دەکرێت.
- **یەک ئامێر، یەک هەژمار بۆ هەر ئەپێک:** لە هەمان وێبگەڕ دەتوانیت ئەپی سەرنشین، شۆفێر و پانێڵ پێکەوە بکەیتەوە، هەر یەکەیان هەژماری خۆی دەمێنێت.
- **گەشتەکانی ڕۆژانە** ئەپی شۆفێر ڕێکیان دەخات (هەروەها پانێڵ و ئەپی سەرنشین بۆ گەشتە تاکەکان)، بۆیە پێویست ناکات کەس ئەپێک بە کراوەیی بهێڵێتەوە.
- زانیارییەکانی وەشانە کۆنەکان (ناو وێبگەڕ) ناگوازرێنەوە. Firebase بە بەتاڵی دەست پێدەکات.

## نەخشەی ڕاستەقینە و GPS (لە v24ـەوە)

**پێویستییەکان لە Google Cloud** (`console.cloud.google.com`، هەمان پرۆژەی taxiakam):
1. **Billing** ← کارتی بانکی دابنێ (بەبێ ئەوە نەخشەکە تاریک دەبێت و «For development purposes only»ی لەسەرە). بودجەیەکی بچووکیش دابنێ لە **Budgets & alerts**.
2. **APIs & Services** ← ئەم سێیانە **Enable** بکە:
   - **Maps JavaScript API** (نەخشە)
   - **Places API (New)** (گەڕانی شوێن). ئاگاداربە: «Places API (New)»، نەک کۆنەکە.
   - **Geocoding API** (ناوی گەڕەک بۆ دەرزی سەر نەخشە)
3. کلیلی نەخشە (`mapsKey` لە `shared/firebase-config.js`) ← **Application restrictions: Websites**، و ئەم ناونیشانانە زیاد بکە: `https://mohammedd0.github.io/*` و `http://localhost/*`. لە **API restrictions** ئەو سێ API ـیە هەڵبژێرە.
4. یاساکانی Firestore دووبارە **Publish** بکە (کۆلێکشنی نوێی `live` و پاراستنی `payAckAt`).

**چۆن کار دەکات:**
- ئەگەر Google Maps بار نەبوو، نەخشە ساختەکەی پێشوو دەمێنێتەوە و ئەپەکە وەک خۆی کار دەکات.
- نەخشەی ڕاستەقینە تەنها کاتێک دەردەکەوێت کە شوێنی سەر نەخشە هەبێت (دەرزی سەرنشین، شوێنی دیاریکراوی بەڕێوەبەر، یان GPS ـی شۆفێر). بەشدارییە کۆنەکان کە شوێنیان نییە نەخشە ساختەکەیان دەمێنێت.
- **سەرنشین** لە داواکاری نوێ دەتوانێت بگەڕێت، دەرزی دابنێت یان «شوێنی ئێستام» بەکاربهێنێت. شوێنی ورد تەنها لە `pax`ـی خۆیدایە. شۆفێران پێش هەڵبژاردن تەنها ئەو نووسینە دەبینن کە سەرنشین نووسیویەتی. دوای هەڵبژاردن شوێنەکە دەچێتە ناو بەشدارییەکە کە تەنها سەرنشین و شۆفێرەکەی دەیبینن.
- **شۆفێر:** لە کاتی گەشتێکی چالاکدا GPS ـی مۆبایل بەکاردێت (هەر ١٥ چرکە یان ١٠٠ مەتر جارێک) و بۆ `live/{uid}` دەنێردرێت، کە تەنها سەرنشینانی ئەو گەشتە دەیخوێننەوە. کاتێک گەشتەکە تەواو دەبێت دەسڕدرێتەوە. لە کاتی گەشتدا شاشەکە ناکوژێتەوە. GPS تەنها لەسەر **https** کار دەکات (github.io یان localhost)، نەک `http://192.168...`.
- **«شۆفێرەکەت نزیکە»** کاتێک شۆفێر دەگاتە ٥٠٠ مەتری وێستگەی سوارکردن (لە یاسا و ڕێکخستن دەگۆڕدرێت).
- **ڕێنمایی ڕێگا:** Google Maps یان Waze بە شوێنی وردی وێستگەکە دەکاتەوە.
- **بەڕێوەبەر:** لە «شار، قەزا و شوێنەکان» دەتوانێت شوێنی هەر قوتابخانە و زانکۆیەک لەسەر نەخشە دیاری بکات (بۆ دووری و نرخی ڕاستتر).
- **شێوازی موچە:** بەڕێوەبەر لە «یاسا و ڕێکخستن» شێوازی نوێ زیاد دەکات. شۆفێر لە «داهات» شێوازەکەی دەگۆڕێت و بەڕێوەبەر ئاگادار دەکرێتەوە و دەبێت پشتڕاستی بکاتەوە.
- **موچەی شۆفێر** لەسەر هەمان بڕی فاتورەی سەرنشین حیساب دەکرێت (بە پێی ڕۆژەکانی مانگ و ڕۆژە ڕاگیراوەکان).
- سنوور: کاتێک ئەپی شۆفێر داخراوە یان لە پشتەوەیە، شوێن نانێردرێت. ئەمە لە ئەپی ئەپستۆردا چاک دەکرێت.

- Firebase Rules گۆڕانکاری ناوێت.

## v43
- **پەڕە بەتاڵەکان:** وێنەکە و دوگمەکە کەمێک لە نووسینەکە دوور کەوتنەوە.
- **وێنەی پرۆفایل لە جیاتی پیت:** خێزان، سەرپەرشتیار، بەشدارییەکان، «کێ سوار دەبێت؟»، هاوڕێ بانگهێشتکراوەکان و ئەدمین. خاوەن ئەکاونت وێنەی خۆی، ئەوانی تر وێنەی بنەڕەت.
- **پرسیارە باوەکان:** ئەدمین لە «پرسیار و پەیوەندی» زیاد/دەستکاری/سڕینەوە/ڕیزبەندی/کوژاندنەوە دەکات و دیاری دەکات بۆ سەرنشین، شۆفێر یان هەردووکیان. `{offerRange}` لە وەڵامدا دەبێتە ڕێژەی ئێستا. سەرنشین پەڕەیەکی جیای هەیە.
- **پەیوەندی:** ئەدمین ژمارەکان دادەنێت (ناونیشان + بۆ کێ). سەرنشین و شۆفێر «پەیوەندی» دادەگرن و ڕاستەوخۆ پەیوەندی دەکەن.
- **سکاڵا:** «یارمەتی و پشتگیری» بوو بە «یارمەتی و سکاڵاکان». شۆفێریش ئێستا سکاڵا دەنێرێت (پارە، سزا، سەرنشین، ئەپ)؛ لە ئەدمین لەگەڵ هی سەرنشین دەردەکەوێت، وەڵام ئاگاداری دەکاتەوە.
- **پرۆفایلی سەرنشین:** «گۆڕینی وشەی نهێنی» چووە «زانیاری پرۆفایل» (سەرووی پاشەکەوت)؛ «ڕێکلام و هەواڵ» لابرا (ڕێکلام تەنها لە سەرەکی).
- **«زیاتر»ی شۆفێر:** سەردێڕی «کار» و «هەژمار و یارمەتی»، ئایکۆنی جیا، «سڕینەوەی هەژمار» چووە خوارەوەی پرۆفایل، «هەواڵ» بوو بە «ئۆفەرەکان» (تەنها ئۆفەر)، قبووڵکردنی شۆفێری نوێ «نوێ»یە.
- **ئاگادارکردنەوەکان** وەک فەیسبووک: نوێ / ئەمڕۆ / دوێنێ / پێشتر، و کاتی کورت (٥ خولەک، ٣ کاتژمێر، دوێنێ ٩:٠٠). شۆفێریش دوگمەکانی هەمووی، گەشت، داواکاری، پارە، هەژماری هەیە.
- **شۆفێری نوێ:** بۆ هەر بەڵگەنامەیەکی پەسەندکراو ئاگادار ناکرێتەوە، تەنها کاتی پشتڕاستکردنەوەی هەژمار؛ ڕەتکردنەوە هەر بە هۆکارەوە دێت.
- Firebase Rules گۆڕانکاری ناوێت.

- **ناڤی خوارەوە** (سەرنشین و شۆفێر) وەک ئینستاگرام: بە هاتنە خوارەوە بچووک دەبێتەوە (تەنها ئایکۆن)، بە چوونە سەرەوە گەورە دەبێتەوە.

- **پەڕە بەتاڵەکان:** وێنە و نووسین و دوگمەکان دێنە ناوەڕاستی بۆشایی، نزیکتر لە پەنجە.
- لابراون: `todayISO`، `adminNoticeAdd`، `syncRunIn`، `allImages`، `.me-photo-note`؛ «نرخی مانگانە ناگۆڕێت» لە گەشتەکانی ئەمڕۆ.

## یەکەم جار

ئەپەکە بە بەتاڵی دەست پێدەکات، هیچ زانیاری نموونەیی تێدا نییە.

1. **پانێڵی بەڕێوەبردن:** `http://localhost/taxikam/admin/` بکەرەوە و بە ئیمەیڵ و وشەی نهێنی ئەو هەژمارەی لە Firebase ← Authentication دروستت کردووە بچۆ ژوورەوە (UIDـەکەی لە `shared/firebase-config.js` و `firestore.rules`دایە).
2. **شۆفێر:** لە ئەپی شۆفێر «ببە بە شۆفێر» بە ٥ هەنگاو: زانیاری کەسی و وێنە، ناونیشان و فریاکەوتن، کارتی نیشتمانی و مۆڵەت، ئۆتۆمبێل (٥ وێنە) و ساڵانە، کۆدی ئاسایش و موچە. وێنەکان لە مۆبایل بە کامێرا یان لە گەلەری بار دەکرێن.
3. شۆفێر دەتوانێت بچێتە ژوورەوە، بەڵام تا پشتڕاست نەکرێتەوە بارێکی سوور دەبینێت و «ئامادەی کارم» کار ناکات.
4. **ئەدمین ← شۆفێرەکان ← شۆفێر:** هەر بەڵگەنامەیەک پەسەند یان بە هۆکار ڕەتی بکەرەوە. شۆفێر هۆکارەکە دەبینێت و لە پرۆفایلەکەیەوە دووبارە باری دەکاتەوە. کاتێک هەموو پەسەند کران، «پشتڕاستکردنەوە و چالاککردن».
5. **جۆری تابلۆ** لە ئەدمین دیاری دەکرێت: شۆفێری نێر تەنها تەکسی (سوور)، شۆفێری مێ تەکسی (سوور) یان تایبەت (سپی).
6. **PDF و چاپ:** لە لاپەڕەی هەر شۆفێرێک دوگمەی «PDF و چاپ»، هەموو زانیاری و وێنەکان. لە پەنجەرەی چاپ «Save as PDF» هەڵبژێرە.
7. **سەرنشین:** لە ئەپی سەرنشین ئەکاونتی نوێ دروست بکە (شار: هەولێر یان سلێمانی).

## تاقیکردنەوە بە چەند ئەکاونت

هەر مۆبایلێک (یان هەر وێبگەڕێک) دەتوانێت هەژمارێکی جیای هەبێت. بۆ نموونە سەرنشین لە مۆبایلێک، شۆفێر لە مۆبایلێکی تر و پانێڵ لە کۆمپیوتەر. لە هەمان وێبگەڕیش هەر سێ ئەپ پێکەوە کار دەکەن.

1. سەرنشین: بەشداری نوێ ← بڵاوکردنەوە بۆ شۆفێرەکان.
2. شۆفێر (چالاک و «ئامادەی کارم»): داواکاری ← قبووڵکردن و نرخ. شۆفێر تەنها داواکاری شارەکەی خۆی دەبینێت.
3. سەرنشین: شۆفێرێک هەڵدەبژێرێت. گەشتەکان ڕۆژانە خۆکار دروست دەبن.
4. شۆفێر گەشت دەست پێدەکات، سەرنشین لە نەخشە دەیبینێت.

## پانێڵی بەڕێوەبردن

لە کۆمپیوتەر باشترە (لە مۆبایلیش کار دەکات).

- **داشبۆرد:** ژمارەکان، کارە چاوەڕوانەکان، ئاگاداری سوور بۆ بەڵگەنامەی نزیک لە بەسەرچوون، ڕاپۆرت و بیرخستنەوەی پاشەکەوت
- **شۆفێرەکان:** پشکنینی بەڵگەنامەکان، پەسەند/ڕەتکردنەوە بە هۆکار، جۆری تابلۆ، ڕاگرتن، PDF، سزا و پاداشت. بەڵگەنامەی بەسەرچوو هەژمار ڕاناگرێت، تەنها ئاگاداری سوور دەدات.
- **سەرنشینەکان:** هەر ئەکاونتێک بە جیا: خێزان، بەشداری، فاتورە، قەرەبوو، خاڵ، پشتگیری
- **بەشداری و داواکاری**، **گەشتەکان**، **هەواڵ**، **سکاڵا و ڕاپۆرت**، **نامەکان**
- **دارایی:** موچەی شۆفێران و فاتورەی هەموو سەرنشینان، «پارە وەرگیرا» بۆ هەر یەکێک
- **هاوبەشەکان:** کۆد و QR بۆ قوتابخانە، زانکۆ و کۆمپانیا (لینکی QR: `passenger/#/register?ref=CODE`). بۆ تاقیکردنەوە لە مۆبایل داشبۆرد بە IPی کۆمپیوتەر بکەرەوە نەک localhost.
- **شوێنەکان:** شار و قەزاکان (زیادکردن و لابردن) و شوێنەکانی هەر شارێک
- **یاسا و ڕێکخستن:** نرخ، کۆمیسیۆن، سزا، کەمترین تەمەنی شۆفێر، کۆنترین ساڵی ئۆتۆمبێل، ماوەی کۆدی ئاسایش، گۆڕینی وشەی نهێنی، پاشەکەوت و گەڕاندنەوە

- ئاگادارکردنەوەی مۆبایل کاتێک ئەپ داخراوە پێویستی بە https هەیە.
- سەرنشین خۆی فاتورەکەی دەکات بە «دراوە»، SOS تەنها نموونەیە و خەڵاتەکان جێبەجێ ناکرێن (دوای Firebase چاک دەکرێن).
- هەندێک کار هێشتا لەسەر مۆبایلی بەکارهێنەر دەکرێن نەک سێرڤەر (بۆ نموونە هەڵسەنگاندنی شۆفێر و سزای «شۆفێر نەهات»). بۆ ئەوەی کەس نەتوانێت دەستکاریان بکات، Cloud Functions پێویستە (پلانی Blaze).

## گۆڕینی زانیاری

| چی | لە کوێ |

| ڕەنگەکان | `shared/core.css` (سەرەوەی فایل) |

## جۆرەکانی هەواڵ (v14)
- **ڕێکلام و هەواڵ**: لە بانێری سەرەوەی سەرەکی سەرنشین دەردەکەوێت (تەواوی پانی شاشە) و دەتوانرێت وێنەی بۆ دابنرێت.
- **ئۆفەر**: تەنها لە بەشی «ئۆفەرەکان»ی خوارەوە دەردەکەوێت و کۆدی تایبەتی هەیە.

## ئەپی شۆفێر و تەکسی هاوبەش (v16)
- ئەپی شۆفێر ٤ بەشی هەیە: **ئەمڕۆ**، **ڕۆتەکان**، **داواکاری**، **زیاتر**. نووسین بە بنەڕەت گەورەیە.
- **ئەمڕۆ**: گەشتی ئێستا یان داهاتوو لەگەڵ یەک دوگمەی گەورە: «بەڕێ کەوتم» ← «گەیشتم» ← «سوار بوو» (یان «نەهات») ← «گەیاندم».
- **ڕۆت**: شۆفێر چەند سەرنشینێک دەخاتە یەک تەکسی (٣ هەنگاو: هەڵبژاردن، ڕیزکردن، پاشەکەوت). هەموو ڕۆژێک خۆکار ئامادە دەبێت. ڕۆتی هاتنەوە دەتوانرێت خۆکار بە پێچەوانەوە دروست بکرێت.
- یاساکانی ڕۆت: تەکسی تایبەت لەگەڵ کەس نابێت؛ منداڵ تەنها لەگەڵ منداڵ؛ خێزان لەگەڵ خێزان؛ «تەنها ئافرەت» تەنها لەگەڵ ئافرەت؛ جیاوازی کات لە ٤٥ خولەک زیاتر نەبێت؛ ژمارەی کەس لە کورسییەکان زیاتر نەبێت (شۆفێر لە پرۆفایل دەیگۆڕێت). نرخ ناگۆڕێت.
- سەرنشین دەبینێت چەند کەس لە تەکسییەکەن، تەنها ناوی یەکەم و ڕەگەز (شوێنی ماڵی ئەوانی تر نیشان نادرێت)، و ڕیزی سوارکردن.
- **داواکاری**: پەڕەیەکی وەک وەڵامدانەوەی تەلەفۆن، نرخی پێشنیارکراو ئامادەیە، تەنها «قبووڵکردن». دەنگ بۆ داواکاری و نامەی نوێ (لە ڕێکخستنەکان دەکوژێتەوە).
- لە پانێڵی بەڕێوەبردن (یاسا و ڕێکخستن): «شۆفێر چەند خولەک پێش کات دەتوانێت دەست پێبکات» (بنەڕەت ٣٠، **٠ = بێ سنوور، بۆ تاقیکردنەوە باشە**)، داخستنی خۆکاری گەشتی لەبیرکراو (١٨٠ خولەک)، ماوەی نێوان وێستگەکان و جیاوازی کاتی ڕۆت.

## v17
- بەڕێوەبەر دەتوانێت شۆفێر زیاد بکات (شۆفێرەکان ← زیادکردنی شۆفێر) و وشەی نهێنی نوێ بۆ شۆفێر دابنێت. شۆفێر خۆی لە ڕێکخستنەکان وشەی نهێنی دەگۆڕێت.
- «نەهات» تەنها دوای چەند خولەک چاوەڕوانی چالاک دەبێت (بنەڕەت ٣، لە یاسا و ڕێکخستن دەگۆڕدرێت). سەرنشینی نەهاتوو گەشتەکەی وەک کراو حیساب دەکرێت و لە مێژووەکەی دەردەکەوێت.
- شۆفێر «گەشتە کۆنەکانم»ی هەیە. دوای تەواوبوونی گەشتەکانی ئەمڕۆ، گەشتەکانی بەیانی پیشان دەدرێن.
- تێبینی سەرنشین (وەک «کورسیی منداڵ») لە وێستگەکانی هەموو ڕۆژێک دیارە.

## v18
- nav ی هەردوو ئەپ وەک واتسئاپ: شریتێکی خڕی سەرپێی. لە سەرەکیی شۆفێر دوگمەی زەردی نامەکان لە لای چەپە.
- سەرەوەی ئەپی شۆفێر وەک سەرنشین: وێنەی پرۆفایل، لۆگۆ، زەنگ. بەروار لە سەرووی گەشتەکانی ئەمڕۆ.
